# Security Policy

## GitKraken application

This repository does not contain the GitKraken application. Report
vulnerabilities in GitKraken itself to GitKraken through their
[bug bounty program](https://gitkraken.com/bug-bounty-program).

## Packaging

Report vulnerabilities in the packaging (`PKGBUILD`, scripts, workflows) with
[private vulnerability reporting](https://github.com/Azd325/gitkraken/security/advisories/new)
of this repository. Do not open a public issue.
